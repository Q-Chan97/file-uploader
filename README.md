# Vaultly File Uploader

This is a full stack file uploader written in Typescript and built with Node.js and Express, created as part of The Odin Project's Node.js course.

**Live:** https://file-uploader-o0fk.onrender.com/login

## Features:
   - File uploading and storing via Supabase
   - User authentication with session persistence
   - Organize files into folders with full CRUD functionality
   - Dynamic routing with parameterized URLs
   - Form validation with custom errors
   - Relational database with Prisma ORM and PostgreSQL

## Concepts Illustrated:
   - MVC architecture
   - Secure password hashing
   - CRUD operations across relational data
   - Cloud file storage integration
   - User authentication and session management
   - Middleware chaining and route protection

## Technologies: 
   - Node.js (Runtime)
   - Express (Node Framework)
   - EJS (Templating)
   - Prisma (ORM)
   - Supabase (Storage)
   - Passport.js + bcrypt (Authorization)
   - Express Validator (Validation)
   - Express Session + Prisma Session Store (Sessions)
